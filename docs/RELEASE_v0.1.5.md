# Bubble Engine v0.1.5

No Linux x86_64, instale o pacote **.deb** com APT ou o **.rpm** com DNF e abra **Bubble Engine** pelo menu. Os dois instaladores mantêm a atualização automática. Para executar sem instalar, baixe o arquivo **portable.zip** da sua plataforma, extraia e abra **BubbleEngine** no Linux ou **BubbleEngine.exe** no Windows. O executável inclui os assets do editor, o runtime e as bibliotecas da engine. Python, CMake e compilador não são necessários para abrir o editor.

| Pacote | Plataforma | Exportação sem compilador |
| --- | --- | --- |
| `bubble-engine-v0.1.5-linux-x64.deb` | Linux x64 (APT) | Em pasta, para Linux |
| `bubble-engine-v0.1.5-linux-x64.rpm` | Linux x64 (DNF) | Em pasta, para Linux |
| `bubble-engine-v0.1.5-linux-x64-portable.zip` | Linux x64 | Em pasta, para Linux |
| `bubble-engine-v0.1.5-windows-x64-portable.zip` | Windows x64 | Em pasta, para Windows |

No Linux, o ambiente gráfico e o driver OpenGL são fornecidos pelo sistema. Exportações em executável único ou para outra plataforma exigem um template pré-compilado compatível. A compilação de templates a partir do código-fonte é opcional.

A [galeria do editor](https://github.com/D4nielStone/cpp-bengine/blob/v0.1.5/README.md#editor-workspaces) mostra a cena Vila Aurora, a edição de uma malha de telhado, o grafo de cenas e a paleta de programação visual. Consulte o [guia de instalação e atualização](https://github.com/D4nielStone/cpp-bengine/blob/v0.1.5/docs/PORTABLE_RELEASE.md) para requisitos e limites.
