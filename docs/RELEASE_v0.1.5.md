# Bubble Engine v0.1.5

Baixe o arquivo **portable.zip** da sua plataforma, extraia e abra **BubbleEngine** no Linux ou **BubbleEngine.exe** no Windows. O executável leva os assets do editor, o runtime e as bibliotecas que acompanham a engine. A exportação em pasta para o mesmo sistema usa o runtime pré-compilado. No Linux, o ambiente gráfico e o driver OpenGL são fornecidos pelo sistema.

A [galeria do editor](https://github.com/D4nielStone/cpp-bengine/blob/v0.1.5/README.md#editor-workspaces) mostra a Vila Aurora na cena, a edição de uma malha de telhado, o grafo de cenas e a paleta de programação visual.
