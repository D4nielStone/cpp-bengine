# Bubble Engine v0.1.5

Baixe o arquivo **portable.zip** da sua plataforma, extraia e abra **BubbleEngine** no Linux ou **BubbleEngine.exe** no Windows. O executável inclui os assets do editor, o runtime e as bibliotecas da engine. Python, CMake e compilador não são necessários para abrir o editor.

| Pacote | Plataforma | Exportação sem compilador |
| --- | --- | --- |
| `bubble-engine-v0.1.5-linux-x64-portable.zip` | Linux x64 | Em pasta, para Linux |
| `bubble-engine-v0.1.5-windows-x64-portable.zip` | Windows x64 | Em pasta, para Windows |

No Linux, o ambiente gráfico e o driver OpenGL são fornecidos pelo sistema. Exportação em executável único e compilação para outro sistema continuam exigindo o ambiente de desenvolvimento descrito na documentação.

A [galeria do editor](https://github.com/D4nielStone/cpp-bengine/blob/v0.1.5/README.md#editor-workspaces) mostra a cena Vila Aurora, a edição de uma malha de telhado, o grafo de cenas e a paleta de programação visual. Consulte o [guia dos pacotes portáteis](PORTABLE_RELEASE.md) para requisitos e limites.
